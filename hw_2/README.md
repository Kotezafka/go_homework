# Gateway & Ledger Services

Домашнее задание включает два сервиса: HTTP-шлюз (`gateway`) и бизнес-логику (`ledger`)


## Как запустить

### 1. Установите зависимости

В каждой папке есть `go.mod`, поэтому зависимости автоматически загрузятся при первом запуске

### 2. Запустите Gateway

```bash
cd gateway
go run main.go
```
В отдельном терминале:

```bash
cd ledger
go run main.go
```


## Домашнее задание 2
### Задание 1
1. Создайте на Go два проекта и напишите две программы Gateway (HTTP-шлюз) и Ledger (бизнес-логика). Инициализируйте go.mod для каждого сервиса. Разместите их в одном репозитории (например, в отдельных папках)

2. В сервисе Gateway напишите функцию main, которая запускает простой HTTP-сервер на порту (например, 8080). Реализуйте обработчик пути __/ping__, который при GET-запросе возвращает строку “pong” со статусом 200 OK. Это поможет проверить, что сервер запущен и отвечает

3. В сервисе Ledger напишите функцию main, которая выводит в консоль примерно такое сообщение “Ledger service started”. Пока можно не поднимать сервер, а просто убедиться, что модуль запускается (в дальнейшем здесь будет gRPC-сервер)

4. Запустите оба сервиса (Gateway и Ledger) отдельно. Убедитесь, что Gateway сервис доступен: отправьте HTTP-запрос на GET __/ping__ (например, через браузер или curl) и получите ответ “pong”


### Задание 2
__Задание необходимо реализовать в сервисе Ledger__

1. Создайте структуру __Transaction__ для представления финансовой транзакции. Необходимо включить поля, например:
- __ID__ — уникальный идентификатор, тип int, можно заполнять автоинкрементом, например (len(slice)+1)
- __Amount__ — сумма, тип float64 или int
- __Category__ — категория траты, тип string
- __Description__ — описание, string
- __Date__ — дата транзакции, можно использовать string для простоты или time.Time

2. Создайте в пакете Ledger хранилище транзакций в памяти (например, срез __[]Transaction__). Инициализируйте пустой срез при запуске сервиса

3. Реализуйте функцию __AddTransaction(tx Transaction)__ в сервисе Ledger, которая добавляет переданную транзакцию в хранилище (в срез). Функция должна возвращать ошибку (error) если, например, сумма транзакции равна 0. При успешном добавлении можно возвращать __nil__

4. Реализуйте функцию __ListTransactions() []Transaction__, которая возвращает все сохранённые транзакции (или их копию) из хранилища. Эта функция пригодится для вывода списка транзакций

5. В функции __main__ сервиса Ledger вызовите несколько раз __AddTransaction__ для теста: добавьте 2–3 произвольные транзакции (с разными категориями и суммами). Затем вызовите __ListTransactions()__ и выведите список транзакций в консоль (через __fmt.Println__ или форматированный вывод). Убедитесь, что все добавленные транзакции отображаются корректно

6. Закоммитьте изменения и обновите репозиторий. Проследите, чтобы в репозитории были инструкции по запуску сервисов для проверки (можно обновить README)


## Домашнее задание 3
__Все задания требуется реализовать в сервисе Ledger__

1. Создайте структуру __Budget__ для хранения информации о бюджете. Поля могут включать:
- __Category__ (категория, на которую выделен бюджет, строка)
- __Limit__ (лимит бюджета, число, например float64)
- __Period__ (например, месяц/год) — как усложнение, для простоты достаточно фиксированного бюджета на категорию

2. Организуйте хранение бюджетов в сервисе Ledger. Например, в виде отображения __map[string]Budget__, где ключом будет название категории или среза бюджетов. Изначально заполните это хранилище парой примеров бюджетов: например, категория «еда» – 5000 рублей

3. Расширьте функцию __AddTransaction(tx Transaction) error__. Теперь при добавлении транзакции функция должна проверять: если для __tx.Category__ задан бюджет (существует в хранилище бюджетов), то суммарная сумма транзакций по этой категории вместе с новой транзакцией не должна превышать __Limit__.
Для этого можно посчитать текущую сумму по категории (пройтись по срезу транзакций или хранить промежуточные итоги) и сравнить с лимитом. Если добавление новой транзакции нарушит бюджет, функция должна вернуть ошибку (например, __errors.New(“budget exceeded”)__) и не добавлять транзакцию

4. Добавьте функцию __SetBudget(b Budget)__ в Ledger, которая добавляет или обновляет бюджет в хранилище бюджетов: например, позволяет изменить лимит для категории. Вызовите эту функцию в __main__, чтобы установить начальные бюджеты, или вместо инициализации через код напрямую

5. Покройте различными тестовыми сценариями функцию __main__: например, установите бюджет на категорию и попробуйте добавить транзакцию, которая не превышает лимит (ожидается успех), и транзакцию, которая превышает лимит (ожидается ошибка). Обработайте ошибку от __AddTransaction__: например, выведите сообщение об отказе. Убедитесь, что транзакции, превышающие бюджет, не сохраняются в списке транзакций

6. Реализуйте функцию __LoadBudgets(r io.Reader) error__, которая читает бюджеты в формате JSON (массив объектов) и добавляет их через SetBudget. В main продемонстрируйте загрузку из файла: os.Open(“budgets.json”) + bufio.NewReader. При ошибках чтения или парсинга верните понятные error
